# Sahyadri Fest 2026 - Ticket Booking System

A full-stack campus event ticketing platform built using Flask, MySQL, Docker, HTML, CSS, and JavaScript.

## Features
- Event selection
- Seat availability system
- QR code ticket generation
- Admin dashboard
- Docker containerization

## Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Flask
- Database: MySQL
- Containerization: Docker

## How to Run
docker-compose up
